# 📝 NLP Text Analyzer Using NLTK

A Python-based Natural Language Processing (NLP) project that transforms raw text into meaningful insights through text preprocessing, linguistic analysis, named entity recognition, and word frequency analysis.

## 🚀 Project Overview

The NLP Text Analyzer processes textual data stored in a CSV file and applies various NLP techniques to analyze and understand the text.

This project demonstrates the practical application of Python, Pandas, and NLTK for text processing and analysis.

## ✨ Features

- **Text Preprocessing:** Removes unnecessary stop words and punctuation.
- **Tokenization:** Splits text into individual words and sentences.
- **Stemming:** Reduces words to their root forms using stemming techniques.
- **Lemmatization:** Converts words into their meaningful base forms.
- **Part-of-Speech Tagging:** Identifies grammatical categories such as nouns, verbs, and adjectives.
- **Named Entity Recognition (NER):** Identifies important entities such as people, organizations, and locations.
- **Word Frequency Analysis:** Counts frequently occurring words in the text.
- **CSV Data Processing:** Reads textual data from a CSV dataset using Pandas.

## 🛠️ Technologies Used

- Python
- Pandas
- NLTK (Natural Language Toolkit)
- CSV Dataset

## ⚙️ Installation and Setup

### Prerequisites

- Python 3.x
- pip (Python package installer)

### Step 1: Clone the Repository

```bash
git clone https://github.com/koyyadahansika-collab/NLP-Text-Analyzer.git
```

### Step 2: Open the Project Folder

```bash
cd NLP-Text-Analyzer
```

### Step 3: Install Dependencies

```bash
pip install pandas nltk
```

### Step 4: Run the Project

```bash
python3 main_final.py
```

**Note:** NLTK may require additional language resources, depending on the operations used in the code. If an NLTK resource error occurs, install the specific resource mentioned in the error message.
